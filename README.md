# 7 дней без Солнца

Научно-популярный 2D-мультфильм. 90 секунд, 1080 × 1920, 30 fps. Композиция Remotion `SunWeek`.

## Запуск

Node.js 24 и npm.

```sh
npm ci
npm run audio
npm run dev
```

## Экспорт

```sh
npm run check
npm run storyboard
npm run render
```

Файлы появляются в `out/`. `sun-week.mp4` содержит H.264 и оригинальный звук. `storyboard.jpg` содержит 19 опорных кадров. Сборка в GitHub Actions включает кадры, видео и монтажные документы. Рендер можно повторить на вкладке Actions через **Render Remotion**.

## Исходники

- `src/scenes.tsx` содержит сцены и их локальную анимацию.
- `src/art/` содержит редактируемую SVG-графику в React, включая риг персонажа, одежду, растение, город, космос и океан.
- `public/art/` содержит самостоятельные SVG-слои. В `public/art/standalone/` — отдельные версии персонажа, планет, города, листьев, льда и гидротермальных источников, открываемые в SVG-редакторе.
- `src/timeline.ts` хранит границы сцен, точки раскадровки и синхронизацию акцентов.
- `scripts/audio.mjs` создаёт три независимые дорожки WAV. Команда `npm run audio -- --table` обновляет таблицу эффектов.
- [Текст диктора](docs/VOICEOVER.md) и [таблица эффектов](docs/SOUND.md) привязаны к хронометражу.

## Допущения сценария

Солнце исчезает вместе с гравитационным воздействием и возвращается в прежнее положение через семь дней. Орбиты показаны схематически. Изменение листа ускорено. Замерзание поверхности показано локально, в холодном районе океана. −18 °C — иллюстративное показание термометра. Для озвучки оставлено пространство в миксе.
